A simple, fast, and responsive web application to convert currencies in real-time.  
Built with a modern UI approach using live exchange rates from the Frankfurter API.

## ✨ Features

- 💵 **Amount Input**: Simple input field to enter the amount you want to convert  
- 🔄 **Real-Time Conversion**: Automatic conversion as you input values and change currencies  
- 🌐 **Currency Selection**: Easy dropdown selection (`<select>`) for base and target currencies  
- 📡 **Live Exchange Rates**: Powered by the Frankfurter API for accurate data  
- 📱 **Fully Responsive Design**: Fluid layout optimized for both mobile and desktop screens  
- 🎨 **Modern UI**: Clean design with smooth interactions  

---

## 🛠️ Technologies Used

- **HTML5** — semantic web structure  
- **CSS3** — modern layouts and responsive design  
- **JavaScript (ES6+)** — dynamic DOM manipulation, event handling, and asynchronous API calls (`fetch`)  
- **Frankfurter API** — open-source currency exchange rate API

## ⚙️ How to Use

1. Open `index.html` directly in your web browser  
2. Enter the amount you want to convert in the input field  
3. Select your **base currency** from the first dropdown menu  
4. Select your **target currency** from the second dropdown menu  
5. The converted amount will display automatically on the screen
